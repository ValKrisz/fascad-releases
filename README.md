# fasCAD

Zusatzmodul für BricsCAD zur automatischen Plattenaufteilung vorgehängter Fassaden.

**Dokumentation und Anleitung**: [docs.fascad.de](https://docs.fascad.de)

**Aktuelle Version**: siehe [Releases](https://github.com/ValKrisz/fascad-releases/releases/latest)

**Kontakt**: info@fascad.de

## Voraussetzungen

- Windows 10 oder 11
- BricsCAD V24, V25 oder V26 (Pro oder höher, 64-Bit)
- Für BricsCAD V26: [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0)

## Installation

Details siehe [docs.fascad.de/installation](https://docs.fascad.de/installation/).
